About

What is this project?

A real-world application of Object-Oriented Programming, built from scratch using only HTML, CSS, and vanilla JavaScript.

This project was built as part of an Object-Oriented Design and Programming (OODP) course. It demonstrates how real software applies OOP — not in theory, but in practice, right here in your browser.

Every element you interact with on this site is powered by a JavaScript class. The navigation, the cards, the contact form — all are objects with properties and methods, keeping the code clean, modular, and extensible.

// Example from this project
class Feature {
  constructor(num, title, desc) {
    this.number = num;
    this.title = title;
    this.description = desc;
  }

  // Method: render HTML
  render() {
    return `<div class="feat-card">`;
  }
}
